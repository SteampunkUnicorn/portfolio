05 / ENGINEERING NOTES

What happens under the hood.

01

One derived dataset

Search and filters produce a single set of visible records. KPIs, charts, and the table all derive from that same selection.

02

Real calculations

Totals are aggregated from row values. Conversion rate is calculated as total conversions divided by total sessions, not an average of row percentages.

03

Accessible data exploration

Native form controls and table semantics, sortable heading buttons, keyboard-operable row details, and text alternatives for charts.

04

Bring your own data

Import compatible CSV or JSON locally. Filtering, visualizations, and export work without transmitting data to a server.
