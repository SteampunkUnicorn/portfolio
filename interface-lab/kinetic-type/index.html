UNDER THE HOOD / 001

A little physics.
A lot of personality.

Every visible character is rendered into its own visual span. Distance from the pointer determines a target offset; a spring-like easing loop carries each letter to that position and back again.

The text stays readable to assistive technology as one label, the interface works without motion, and all controls use native HTML inputs.
