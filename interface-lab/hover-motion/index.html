02 / MOTION PRINCIPLES

Responsive, not restless.

Motion is a form of feedback. The goal is to communicate state, not decorate every pixel.

01

Respect the target

Magnetic effects should never pull a control away from its hit area or make the target difficult to activate.

02

Keep a way out

Hover should enhance an interface, not hide essential information or make functionality depend on a mouse.

03

Honor reduced motion

Pointer-driven movement is disabled when the user requests reduced motion. Keyboard focus remains visible and useful.

03 / IMPLEMENTATION NOTES

Choose the right tool.

Most hover effects can be built with CSS transitions. Use JavaScript when the effect needs pointer coordinates, and keep those updates scoped to the element being explored.

INTERACTION NOTES01 — 03
01transition: transform 320ms cubic-bezier(.2,.8,.2,1);
02element.style.setProperty('--pointer-x', `${x}%`);
03@media (prefers-reduced-motion: reduce) { … }

These are illustrative patterns, not a copy-ready implementation for every component. Always test actual interaction and focus behavior.
