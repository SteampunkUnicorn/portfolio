04 / UNDER THE HOOD

Let the platform do the hard part.

The panel uses the Popover API to enter the top layer, and CSS Anchor Positioning to follow the trigger. position-try-fallbacks asks the browser to select another side when the preferred one overflows the viewport.

This is a deliberate progressive-enhancement experiment: browsers without anchor positioning use a minimal JavaScript positioning fallback. The native version needs no per-frame geometry calculations. Note: narrowing the stage alone does not change the viewport collision boundary. The scroll scenario shows how a top-layer popover follows an anchor in scrolling content.
