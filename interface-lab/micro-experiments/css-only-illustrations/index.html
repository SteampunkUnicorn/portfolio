Small experiment / 006

CSS-Only Illustrations.

Create small recognizable objects with CSS primitives.

Controls

No SVG, bitmap assets, or canvas — just nested elements, gradients, transforms, and borders.

Under the hood

What’s happening?

Each scene is a set of CSS shapes composed from gradients, border radii, shadows, and transforms. Switching scenes never downloads an image. The objects are marked decorative; the labeled selector communicates what is displayed.
