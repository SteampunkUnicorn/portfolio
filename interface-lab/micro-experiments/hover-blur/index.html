Small experiment / 009

Focus one, dim the rest.

Hovering one row blurs its siblings, using only the list's :hover state and :not().

Under the hood

What’s happening?

The list responds to hover by shifting visual focus to the active item. As the pointer moves over a link, the remaining items fade and soften with a subtle blur, while the hovered item slides horizontally to create a sense of movement.

The effect uses CSS sibling targeting to dim the non-hovered items, with transitions smoothing the change in opacity, blur, and position. No JavaScript is needed—the browser handles the interaction entirely through :hover and CSS transitions.
