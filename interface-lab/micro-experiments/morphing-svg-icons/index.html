Morphing SVG Icons.

Switch between meaningful states with a shared, animated vector geometry.

Menu

Controls

Many states, one SVG path. Choose a shape to animate to it.

Under the hood

What’s happening?

Each icon uses three line segments with matching coordinate structures. JavaScript interpolates their coordinates to transition between states, including directional arrows, toggles, and playback controls. Selected states use aria-pressed, and animation respects reduced-motion preferences.
