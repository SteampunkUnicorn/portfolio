Morphing SVG Icons.

Switch between meaningful states with a shared, animated vector geometry.

Menu

Controls

Four states, one SVG path. Choose a shape to animate to it.

Under the hood

What’s happening?

Each icon is the same three-stroke SVG path with identical coordinate counts. JavaScript interpolates the path coordinates, rather than trying to tween incompatible SVG commands. Selected states use aria-pressed, and animation can collapse to a single frame for reduced motion.
