Impossible Checkbox.

A mischievous consent-free toggle with a fair, keyboard-friendly escape hatch.

◡

Go ahead. Try it.

Controls

The checkbox stays operable by mouse, touch, and keyboard. The joke has a guaranteed ending.

Under the hood

What’s happening?

This is a deliberately mischievous control, not a pattern to copy into real forms. The checkbox remains a native checkbox, the status message is announced politely, and the user can disable the behavior immediately. There is no consent, purchase, or consequential decision involved.
