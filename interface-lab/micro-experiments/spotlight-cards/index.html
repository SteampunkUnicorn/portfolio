Spotlight Cards

Under the hood

What’s happening?

Each card contains a radial gradient that acts as a soft spotlight, revealing itself when the card is hovered. The highlight is positioned using CSS custom properties (`--x` and `--y`), allowing JavaScript to move the light source in response to the pointer.

The gradient lives in a `::before` pseudo-element, keeping the visual effect separate from the card's content. Its opacity transition creates a gradual fade rather than an abrupt appearance, while `overflow: hidden` keeps the glow contained within the card's rounded edges.

The result is a subtle, pointer-responsive lighting effect that adds depth without shifting the layout or interfering with the content.
